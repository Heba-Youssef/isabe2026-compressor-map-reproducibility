# Compressor Map Data

The converted `.mat` files in this folder were prepared from maps listed in the GasTurb component map collection and its cited open-literature sources.

The paper cites the GasTurb map collection and, where possible, the original literature source associated with each map. The map labels used in the scripts are file identifiers, not standard compressor names.

Confirm redistribution permission before pushing the converted map files to a public repository. If redistribution is not permitted, remove the `.mat` files and instruct users to prepare the converted maps locally in this folder.
